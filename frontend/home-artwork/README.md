# Иллюстрации Home

Оригинальные материалы предоставлены владельцем Soul Arkana для Sprint 14.2.
Это архив исходников, а не runtime-каталог: Vite публикует только оптимизированные
варианты из `public/home/`. Никаких внешних CDN или runtime-конвертеров нет.
Все 16 PNG сохранены без изменения пикселей; сомнительные варианты не удалены.

Файлы не содержат маркетингового текста. Цифры в иллюстрации нумерологии —
декоративные символы, не подписи интерфейса. Заголовки, описания и ссылки
остаются локализованным HTML. Оригиналы не являются утверждённой runtime-колодой
Таро и не подменяют её.

## Оптимизация

Однократная офлайн-конвертация через браузерный WebP encoder; в приложении canvas
не используется. Сохранено соотношение сторон, кроме намеренно выделенного
мобильного кадра Hero. Прозрачность разделителя сохранена.

| Материал          | Исходник                    | Выходная ширина | Качество WebP |
| ----------------- | --------------------------- | --------------- | ------------- |
| Tarot Hero        | 1672 × 941                  | 1280 / 1672     | 0.90          |
| Tarot Hero mobile | Кадр x=640, y=0, 1032 × 941 | 640 / 960       | 0.88          |
| Cosmic background | 1672 × 941                  | 800 / 1440      | 0.76          |
| Numerology        | 1374 × 1145                 | 480 / 960       | 0.86          |
| Portrait          | 1374 × 1145                 | 480 / 960       | 0.86          |
| Celestial divider | 2172 × 724, alpha           | 640             | 0.88          |

Совокупный размер 11 WebP: 1 596 778 байт (около 1.52 MiB), против
32 183 872 байт всех PNG. Один посетитель не загружает все размеры:
`picture/srcset/sizes` выбирают подходящий вариант. Hero загружается
с высоким приоритетом; вторичные сцены и разделитель — лениво.

Исходный технический `.DS_Store` убран из public в временный QA-каталог,
не используется и не предназначен для Git. Скриншоты и конвертер тоже
остаются за пределами репозитория.
