# Sprint 19.2 — navigation and optional birth date

The existing navigation registry remains the single source for destinations. The shared header opens one native modal dialog on all routes. Desktop Tarot Result retains its accepted reading rail. Opening/closing the menu never changes the current route or resets product state. The native modal blocks background interaction and contains keyboard focus; Escape, Close and an outside click close it and return focus to the header trigger. Navigation links retain ordinary modified-click behavior.

Portrait birth date remains optional. The existing validator alone controls submission and whether the symbolic preview receives a date. Invalid/underage/future dates show no derived preview; skipping shows no stale sign, number or date. All formulas, answers, generation and persistence contracts remain unchanged. The preview is an annotation, not a report or a psychological conclusion.

Numerology retains Life Path, Birthday/First impression, dominant Year and supporting Month/Today. This pass adjusts chapter spacing and axes. Responsive Western artwork, masking and registry remain unchanged; Chinese Zodiac and Product Storage V2 remain disabled.

Browser verification uses isolated test data. Card of the Day must be checked both with working storage and a simulated write failure. A warning from an owner screenshot alone cannot establish the owner's browser storage condition. Keyboard focus on Portrait chapter headings follows the accepted closing heading treatment; forced colors retain system Highlight.
