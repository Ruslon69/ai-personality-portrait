# Основной пользовательский путь

## Базовый сценарий

1. Пользователь открывает сайт.
2. Сразу понимает назначение продукта: создать персональный цифровой портрет для саморефлексии и развлечения.
3. Нажимает «Создать мой портрет».
4. Выбирает один или несколько доступных видов анализа и видит, какие данные понадобятся.
5. Проходит быстрые вопросы с готовыми вариантами ответов; при желании добавляет комментарий своими словами.
6. Записывает голосом подготовленный текст, если выбрал голосовой анализ.
7. Вводит дату рождения для нумерологического и зодиакального блоков.
8. Видит красивый, короткий и понятный процесс создания портрета с индикатором прогресса.
9. Получает бесплатную краткую часть результата с обозначением ограничений и природы интерпретационных блоков.
10. При желании открывает полный отчёт после предложения оплаты.
11. Сохраняет результат или делится карточкой.
12. Приглашает другого человека для анализа совместимости.
13. В любой момент находит настройки данных и может удалить свои данные.

## Путь без регистрации

Пользователь может начать прохождение без аккаунта. До момента сохранения результата сервис использует временную сессию и запрашивает только данные, необходимые для выбранных модулей. Пользователь видит краткий результат без обязательной регистрации.

Если пользователь завершил сессию без сохранения, временные данные должны удаляться в соответствии с заранее определённым сроком хранения. Этот срок — открытый продуктовый и юридический вопрос.

## Момент предложения регистрации

Регистрация предлагается после появления ценности, а не на первом экране: при сохранении результата, открытии полного отчёта, оплате, создании постоянной ссылки для публикации или запуске совместимости. Формулировка должна объяснять пользу: сохранить доступ к портрету и управлять данными.

Пользователь не должен терять уже пройденные шаги из-за предложения регистрации.

## Момент предложения оплаты

Предложение оплаты появляется после бесплатной краткой части, когда пользователь уже видит основу своего портрета. Экран объясняет, что именно добавит полный разбор: больше связей между выбранными блоками, расширенные рекомендации и дополнительные карточки.

До оплаты должны быть ясны цена, состав полного отчёта, условия доступа и способ управления данными. Бесплатная часть остаётся самостоятельной и полезной.

## Путь совместимости

1. Пользователь из готового портрета выбирает «Сравнить совместимость».
2. Сервис объясняет, что сравнение — это бережная интерпретация, а не вердикт об отношениях.
3. Пользователь создаёт приглашение и отправляет его другому человеку.
4. Второй человек открывает приглашение, знакомится с назначением сравнения и самостоятельно проходит нужные части анализа либо даёт явное согласие на использование своего уже созданного портрета.
5. После согласия обоих сервис создаёт результат: сильные стороны, различия, возможные зоны напряжения и практические советы для диалога.
6. Каждый участник получает понятный доступ к удалению своих данных и отзыву согласия на дальнейшее использование в сравнении.

## Если нет доступа к микрофону

Сервис объясняет, зачем нужен микрофон, и предлагает повторить запрос разрешения после действий пользователя в браузере. Если доступ не предоставлен, пользователь может:

- продолжить создание портрета без голосового блока;
- вернуться к записи позже;
- получить подсказку по включению доступа в настройках браузера.

Отказ от микрофона не должен блокировать весь путь, если пользователь не выбрал голосовой анализ как обязательную для себя часть.

## Если запись некачественная

Перед отправкой сервис проверяет базовые признаки: слишком короткую запись, отсутствие слышимой речи или выраженный шум. Вместо технического сообщения пользователь получает понятную подсказку: перейти в тихое место, говорить ближе к микрофону или записать текст ещё раз.

Пользователь может прослушать, перезаписать или пропустить голосовой блок. Нельзя создавать категоричные выводы по некачественной записи.

## Если прохождение прервано

Во время сессии ответы и выбранные шаги сохраняются в пределах согласованного срока, чтобы пользователь мог продолжить с того же места. При возвращении сервис показывает следующий незавершённый шаг и кратко напоминает, что осталось.

Пользователь должен иметь возможность начать заново и удалить временные данные. До регистрации восстановление на другом устройстве не гарантируется; это необходимо явно объяснить.
