This inventory describes the code shipped in the current static web application. It is an engineering record, not a legal opinion. Re-check it whenever storage, networking, analytics, accounts, payments or hosting behavior changes.

## Owned browser keys

Current owned keys are enumerated in `frontend/src/features/product-storage/constants/index.ts`. They include legacy `app:*` and `ui-theme` keys plus Product Storage V2 active, backup, migration, recovery and temporary transaction keys. A product reset must enumerate only these owned keys; `localStorage.clear()` is prohibited.

## Network and third parties

- The UI has a reusable API client, but no current product flow calls it.
- No analytics, advertising, tracking pixel, cookie, third-party script, external font or external image request is configured.
- The production runtime smoke recorded no external request for the audited routes.
- Cloudflare Pages is the selected static host and CDN. It necessarily receives ordinary HTTP request data such as IP addresses, browser/device headers, requested URLs, timestamps, and network/security logs while serving the application.
- Current product code does not upload Portrait answers, Tarot selections, Numerology inputs, voice recordings or other product content to Cloudflare APIs or another external service.
- Static application assets are served from the Soul Arkana Cloudflare Pages origin and, later, the attached production custom domain.

## Retention boundaries

- Volatile Portrait and voice state lasts only for the live page/application session.
- `sessionStorage` lasts for the browser session subject to browser behavior.
- `localStorage` has no time-based expiry. Tarot history has a user-selected record limit; other local preferences remain until replaced or site data is removed.
- There is no server account, backup or recovery service in the current implementation.
