## Производные

Офлайн-конвертация тем же браузерным WebP encoder, что в Sprint 14.2.
Canvas, encoder и QA-файлы не входят в приложение; зависимостей не добавлено.

Мобильный кадр: x=240, y=0, ширина=1056, высота=1024 исходного изображения.
Он сохраняет центральную карту и окружающую сцену; дальнейшее CSS-кадрирование
выполняется только для декоративного entry artwork, не для Premium Tarot карт.

Hero использует `picture/srcset`, высокий приоритет и зарезервированные размеры.
Setup использует только приглушённый 960px вариант как атмосферный фон.
Все четыре производные занимают 1 067 850 байт; один посетитель не загружает
все варианты. Оригинал не должен появляться в production build.

Стили entry/setup находятся в отдельном CSS module. Класс setup не монтируется
на шаге reveal; принятые стили и механика Reading не изменены.
