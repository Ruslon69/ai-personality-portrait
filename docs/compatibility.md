# Модуль совместимости

Совместимость — это бережное сравнение двух портретов и повод для разговора. Это не процент «идеальности», не оценка ценности людей и не прогноз будущего отношений.

## Сценарии

- **Романтическая пара** — основной сценарий MVP: люди уже состоят в отношениях и хотят лучше понять сходства, различия и способы разговора.
- **Начало отношений** — более осторожный сценарий для людей, которые только знакомятся; допустим как интерпретационный контекст, но не как совет принимать решение об отношениях.
- **Друзья** — будущий сценарий, ориентированный на стиль общения, общие интересы и поддержку.
- **Коллеги и рабочая совместимость** — только будущая функция. Результат нельзя использовать для кадровых решений, найма, оценки сотрудника или распределения возможностей.

## Способы запуска

1. Сравнение двух зарегистрированных пользователей, если оба явно согласились использовать сохранённые портреты.
2. Приглашение по приватной ссылке: второй человек проходит нужные части анализа или соглашается подключить сохранённый портрет.
3. Ввод пользователем базовых данных другого человека без его голосовой записи — только для ограниченного предварительного сравнения. Такой ввод не даёт права на полноценный совместный разбор.
4. Полноценный совместный разбор создаётся только после явного согласия обоих участников.

## Результат совместимости

В результате не выводится единый «процент совпадения». Сначала пользователь видит общий короткий вывод, затем при желании раскрывает отдельные темы:

- сильные стороны пары;
- различия;
- стиль общения;
- эмоциональная динамика;
- бытовые привычки;
- близость и личное пространство;
- принятие решений;
- конфликты и восстановление после них;
- общие интересы;
- практические советы;
- несколько вопросов для пары.

Каждая тема описывает возможные паттерны и конкретный способ обсудить их. Не все темы должны появляться, если для них недостаточно добровольно предоставленных данных.

## Инфографика

Инфографика объясняет сравнение, а не превращает его в игру с рейтингом. Она включает:

- пересечение двух профилей;
- несколько понятных шкал по отдельным темам;
- сильные зоны и зоны различий;
- карточки с раскрытием деталей;
- лёгкие интерактивные точки с коротким пояснением;
- переключение между кратким и подробным режимом;
- отдельную карточку результата для публикации.

В одном представлении показывается только необходимое: шкалы не должны создавать иллюзию точного измерения, а карточка для публикации не должна раскрывать чувствительные детали.

## Формулировки

Запрещено писать:

- «вы не подходите»;
- «вам нужно расстаться»;
- «отношения обречены»;
- «этот человек вам изменит»;
- любые гарантии будущего;
- оценки одного человека как хорошего или плохого.

Допустимый стиль:

- «У вас разные способы выражать эмоции».
- «В этой ситуации может возникать недопонимание».
- «Вам может помочь такой способ разговора».
- «Это различие может как дополнять вас, так и создавать напряжение».

Выводы формулируются вероятностно, уважительно и с практическим следующим шагом. Нумерологические и астрологические части результата маркируются как интерпретации для развлечения и саморефлексии.

## Приватность и согласие

- Каждый участник видит, какие данные будут использованы в сравнении, до согласия.
- Согласие на участие, использование сохранённого портрета и создание совместного результата должно быть явным и отдельным.
- Голосовая запись одного участника не становится доступна другому участнику.
- Участник не получает полный доступ к индивидуальному портрету другого человека, если тот не выбрал это отдельно.
- При ограниченном вводе данных о другом человеке не создаётся его профиль и не формируются выводы о его личности по голосу или чувствительным признакам.
- Любой участник может отозвать согласие и удалить свои данные; после этого совместный результат перестаёт быть доступен в объёме, зависящем от его данных.
- Приватная ссылка должна быть управляемой: её можно отозвать, а её назначение и статус понятны обоим людям.
- Результат нельзя использовать для решений о работе, кредитах, образовании, лечении или иной оценки человека третьими лицами.

## MVP

В MVP основной сценарий — романтическая пара. Доступны приватное приглашение, согласие обоих участников, краткий и подробный режимы результата, карточка для публикации и темы, перечисленные выше, если они поддержаны выбранными данными. Ввод базовых данных другого человека допускается только как ограниченный предварительный сценарий без полноценного совместного разбора и без голоса.

## Будущие лёгкие интерактивности

- Вопросы для пары после отдельной карточки результата.
- Ненавязчивые точки на инфографике, раскрывающие совет или тему для разговора.
- Режимы дружбы и рабочих отношений с самостоятельной правовой и продуктовой оценкой.
- Сравнение изменений в совместном результате только при новом согласии обоих участников.

Эти идеи не входят в MVP и не должны превращать сервис в социальную сеть или ежедневный трекер отношений.

## Открытые вопросы

- Какой минимальный набор данных достаточен для полезного предварительного сравнения без согласия второго человека?
- Какие темы полной совместимости требуют отдельного выбора обоих участников?
- Как будет устроено удаление или пересчёт общего результата после отзыва согласия одним из участников?
